# SpeedTest

Консольная утилита выполняет 10 последовательных GET-запросов по указанному URL.
Она показывает текущую скорость скачивания в кбит/с, а затем выводит среднее
время запроса и общий объём скачанных данных в байтах. URL должен вести
непосредственно к файлу, так как утилита не следует перенаправлениям.

## Сборка
Требуются Python 3.11 или новее и установленный [uv](https://docs.astral.sh/uv/).
Выполните команды из корня репозитория. uv установит зависимости по `uv.lock`.


```sh
uv build
```

## Запуск

Выполните 

```sh
uv run --locked speedTest "https://example.com/file.zip"
uv run --locked speedTest --help
```

В терминале индикатор обновляется на одной строке примерно каждые 0,2 секунды. При перенаправлении
вывода каждое обновление записывается отдельной строкой.
